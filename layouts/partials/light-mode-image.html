{{/* Returns the URL of a post's light-mode featured image, or "". Featured images are drawn on a dark background; each post bundle may also carry light-mode.jpg (generated by scripts/featured_light_variants.py). Templates render both and custom.css shows the one matching the theme. Its name must not contain feature, cover, thumbnail or background: the theme picks the featured image by those globs. Params: page (the post), size (Resize spec, e.g. "600x"). */}} {{ $url := "" }} {{ with .page }} {{ if not .Params.featureimage }} {{ with (.Resources.ByType "image").GetMatch "light-mode.*" }} {{ $url = .RelPermalink }} {{ if not (or (site.Store.Get "disableImageOptimization") (eq .MediaType.SubType "svg")) }} {{ $url = (.Resize $.size).RelPermalink }} {{ end }} {{ end }} {{ end }} {{ end }} {{ return $url }}
